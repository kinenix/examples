# Get_Artbook

จากเว็บ https://books.toscrape.com/index.html
จงดึงข้อมูลจากเว็บหนังสือประเภท Art ทุก page
โดยเงื่อนไขการดึงข้อมูลของหนังสือจงดึงข้อมูล ชื่อ, rating, ค่าราคา, และสถานะคงคลัง
โดยดูว่าถ้า rating มากกว่าหรือเท่ากับ 3 ดาว ค่อยดึงข้อมูล
ดึงข้อมูลลงในไฟล์ CSV ตั้งชื่อว่า Artbook โดยมี column ดังข้อมูลดังกล่าว
ถ้ามี error ให้วนทำหน้าต่อไปของเว็บ ถ้าเปิดเว็บไม่ได้ให้แจ้งว่าเปิดเว็บไม่ได้และ error ออกมา
